# 在 Windows 上使用 Agent 运行远程 VASP 计算

本项目用于在 Windows Codex IDE 中通过自然语言驱动远程服务器上的 VASP 计算。Agent 会经由 SSH 查阅课题组教程与标准算例、生成并预检输入文件、按需提交 PBS 作业，并在启用监听后将作业状态回传至原聊天窗口。所有计算文件与结果均保留在服务器上。

## 环境要求

- **必需**：Windows、Python 3.10+、OpenSSH 客户端；从本仓库部署还需安装 Git 并具备仓库读取权限。
- **可选（PBS 作业回传监听）**：Node.js 18+、已登录的 Codex Desktop。

## 快速部署

在 Windows Codex IDE 中新建一个专门用于远程 VASP 计算的项目目录，授予完全访问权限后，将下方指令直接发送给 Agent：

> 请从 [这个仓库](https://github.com/hqt6680/hpc-vasp-workflows) 将 VASP 工作流部署到当前 Windows 文件夹。缺少任何信息时请发独立问答卡，一次只问一件事，等我回复后再继续。如果没有可用的 SSH 别名，请引导我配置并保存免密登录。部署完成后，请确认可以读取服务器上的 AICC；如果我启用了 PBS 作业回传，也请帮我完成回传测试。

### 部署流程说明

1. **SSH 连通与免密配置**  
   若本机已有可用的集群 SSH 别名，将直接沿用；否则 Agent 会逐项询问别名、服务器地址、登录账号与端口并写入配置。首次上传公钥时，可能需要在本机终端输入一次服务器密码（密钥口令也仅在本机终端输入）。配置完成后，Agent 会自动验证免密登录。如需在 VS Code 中浏览服务器文件，在 Remote - SSH 中选择同一别名即可。

2. **远端工作目录与 AICC 初始化**  
   连通后，Agent 会询问你的服务器工作目录，并在该目录下创建专属的 `.auto-computational-chemist/`，包含 AICC 流程、工具脚本以及记录工作根目录的站点说明。

3. **按需配置以下选项**（逐项询问，已有配置直接沿用）
   - **是否启用组内默认知识库？**  
     启用后，工作目录中的 `knowledge/default/` 将指向 `/public/home/zjt/.examples/Master/` 下的教程与索引，`knowledge/examples/` 指向同一发布库中的完整标准算例。即使跳过，仍会安装专属 AICC。
   - **是否立即学习个人算例？**  
     选择“现在学习”后填入个人算例目录，Agent 会将参数设置与结果验收经验整理至 `knowledge/personal/`；也可以选择“以后再说”。
   - **是否启用 PBS 作业回传？**  
     启用后，已登记作业结束时会自动提醒原聊天；也可以留到首次提交作业时再开启。

## 使用示例

将结构文件放进服务器算例目录后，可以直接这样向 Agent 发起任务：

> 我的 POSCAR 在〈服务器算例目录〉。请参考组里已验收的能带算例，帮我准备一套无 SOC 的自洽和能带输入，解释一下 k 点怎么选，先做到预检。

典型执行流程分为四步：

1. **匹配参考算例**  
   Agent 先读取工作目录规则。若已启用默认知识库，会根据目标物理量、体系结构与磁态筛选已验收算例并读取对应 `workflow.md`；遇到“自洽 → 能带”等多阶段任务时，会先查阅 AICC 的 `comp-chem-workflow`，再生成适配当前材料的输入文件。
2. **输入文件预检**  
   Agent 读取 AICC 的 `tools/vasp/SKILL.md`，在算例目录运行 `check_inputs.py`，核对元素顺序与 `POTCAR` 是否一致、共线/非共线磁矩分量数是否正确等。此阶段只做检查，方便你在提交前复核输入与提示。
3. **提交 PBS 作业**  
   经你确认提交后，Agent 按 AICC 的 `tools/hpc-submit/SKILL.md` 核对计算资源，并使用 `qsub` 提交当前阶段脚本。组内新算例默认使用 VASP 6.5.1：
   - 共线计算：使用 `std.pbs`，通过 MPI 启动 `$HOME/bin/vasp6.5-wannier`。
   - SOC 或非共线计算：使用 `ncl.pbs`，启动 `$HOME/bin/vasp6.5so-wannier`。
4. **结果解析与验收**  
   作业完成后，Agent 调用 AICC 的 `parse_vasp.py` 提取能量、受力等关键信息，并结合计算目标核查收敛状态（例如计算能带前先确认自洽电荷密度可用），确认无误后再推进下一阶段。

## 作业回传与恢复清理

- **作业回传**：如需在作业结束时自动提醒原聊天，可按需启用 Windows 监听器（需要 Node.js 18+ 与已登录的 Codex Desktop）。
- **清理本机部署**：直接在项目聊天中发送“恢复本机部署”即可。该操作仅清理本机部署文件，你的个人笔记以及服务器上的作业和知识库均会保留。

更多细节请参阅：[部署、监听与恢复说明](share/vasp-pbs/references/setup.md)。
