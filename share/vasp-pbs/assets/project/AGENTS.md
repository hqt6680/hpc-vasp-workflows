# VASP 知识库

- 首次部署、切换默认库或收到“学习这个目录”时，读取已安装的 `vasp-pbs` 技能及其 `references/setup.md`。后续对话先读取本项目的 `.vasp-local/knowledge.md`，按当前选择使用默认库和个人笔记。

## PBS 回传

- 通过本人配置的 SSH 别名连接集群，核对账号、主机和工作根，并读取站点及项目规则。按本站实际调度器、程序版本、数据和资源安排计算。
- 只登记已经提交且需要跨轮等待的 PBS 作业。登记后启动本机监听，回传后独立核对调度结果和计算输出。
- 处理终态前对账算例已有作业。完成验收或故障处理后运行 `python scripts/pbs_watch.py ack <event_id>`。需要继续计算时，先验收前置步骤，再提交当前可运行的下一步。
- 监听设置和恢复命令见 `scripts/README.md`。如已安装 `$vasp-pbs`，可用它配置或排查回传。
